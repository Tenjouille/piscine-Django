Render static web page

{% endblock head %} {% block content %}

Writting a simple template file in html, js, CSS, ... allows you to create a new static web page ready to be rendered.

To do so, django needs a HttpResponse object (or an exception).

Those are returned from functions presents in app/views.py.

Files in templates folder can be instanciated as a Python object with the function get_template() from the template library in django.

Then the render() method from this object return the template's content that can be given to the HttpResponse you need to return.
