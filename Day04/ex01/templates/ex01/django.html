Django is a free and open-source, Python-based web framework

Following the model-template-views (MTV) architectural pattern, the framework was named after guitarist Django Reinhardt.

Some important dates :

  • Autumn 2003 : Django creation
  • July 2005 : Django is publicly released
  • June 2008 : Django Software Foundation (DSF) would continue to maintain Django in the future
